# Rishabh & Sanjana — Wedding Invitation Website

## Included
- `index.html` — responsive, mobile-first invitation website
- `assets/` — add your couple photograph, gallery images, and optional music here

## Current design
- Ivory, olive, sage, and antique-gold palette
- Bodoni Moda display typography with Manrope body typography
- Dedicated Save the Date / date-reveal section
- RSVP section removed

## Before publishing
1. Replace the hero photo placeholder with your couple photograph.
2. Add 6–10 pre-wedding photographs to the gallery and update image paths in `index.html`.
3. Add an instrumental music file and music control if desired.
4. Check both venue map links and replace them with exact map links if desired.

## Publish free with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the public URL after deployment finishes.

The website is prepared but is not publicly hosted until you complete publishing.
